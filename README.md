# WC-PREDICT

Machine learning model for predicting the 2026 FIFA World Cup winner using XGBoost and Monte Carlo simulation.

## How it works

1. **Data** — downloads historical international match results
2. **ELO ratings** — computes dynamic ELO ratings for every national team from 1993 onward
3. **Feature engineering** — builds a feature matrix per match: ELO differential, recent goals scored/conceded, win rate
4. **Model** — trains an XGBoost classifier to predict match outcomes (home win / draw / away win)
5. **Simulation** — runs 50,000 Monte Carlo simulations of the full tournament bracket, producing win probabilities for every team at every round

## Usage

```bash
pip install -r requirements.txt

python main.py train      # fetch data, compute ELO, train model
python main.py predict    # run Monte Carlo simulation
python main.py all        # train then predict (default)

# Custom number of simulations
python main.py predict 100000
```

Output is printed to the console and saved to `data/predictions.csv`.

## Features used

| Feature | Description |
|---|---|
| `elo_diff` | ELO rating difference (home − away) |
| `elo_home` / `elo_away` | Absolute ELO ratings |
| `neutral` | Whether the match is played at a neutral venue |
| `home_goals_scored` | Average goals scored in last 10 matches |
| `home_goals_conceded` | Average goals conceded in last 10 matches |
| `home_win_rate` | Win rate in last 10 matches |
| (same three for away) | |

## Project structure

```
src/
  data_loader.py   # fetch and filter historical results
  elo.py           # ELO rating computation
  features.py      # feature matrix construction
  model.py         # XGBoost training and inference
  simulation.py    # Monte Carlo tournament simulation
  tournament.py    # group definitions and bracket logic
main.py            # CLI entrypoint
visualize.py       # results visualisation
data/
  model.joblib     # trained model (generated by train step)
  predictions.csv  # simulation output (generated by predict step)
```
